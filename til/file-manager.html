Identifying the default file manager

Thunar as default file manager

Locate the desktop file:

$ find /usr/share/applications/ -iname "*thunar*"
/usr/share/applications/thunar-volman-settings.desktop
/usr/share/applications/thunar.desktop
/usr/share/applications/thunar-bulk-rename.desktop
/usr/share/applications/thunar-settings.desktop

Assign it

$ xdg-mime default thunar.desktop inode/directory
