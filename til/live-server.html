Introduction

Installation

npm install -g live-server

Serving

cd static
live-server

If the default port is already in use then another one will be selected.

$ http://0.0.0.0:8080 is already in use. Trying another port.
Ready for changes
Serving "/full/path/of/my/static/page" at http://127.0.0.1:34413

This address will automatically opened on the default browser.
