vim

Instalação do vundle

git clone https://github.com/VundleVim/Vundle.vim.git ~/.vim/bundle/Vundle.vim

Ctrlp

Ctrlp modified

Easily open locally modified files in your git-versioned projects.

Uso a versão que lista os arquivos [modificadas[(https://github.com/jasoncodes/ctrlp-modified.vim)

Instalação

Acrescentar no .vimrc

Bundle 'kien/ctrlp.vim'
Bundle 'jasoncodes/ctrlp-modified.vim'

Rodar o VundleInstall

Atalhos

map <Leader>m :CtrlPModified<CR>
map <Leader>M :CtrlPBranch<CR>
